# Cursor チェンジログ要約

出典: [Cursor Changelog](https://cursor.com/ja/changelog)（日本語版は直接取得できなかったため、同内容の英語版を要約）

## 2026年9月10日 — Cursor Projects（ベータ）

大きな仕事（機能、移行、アプリ全体）を長期間にわたって進められる新機能。左ナビから開きます。

- **コーディネーター**は自分ではコードを書かず、計画・委譲・レビュー依頼を担当
- 必要なら何千ものサブエージェントを並列起動
- **Cloud Agents**上で動くので、PCを閉じても止まらない
- プロジェクト単位の**共有コンテキスト**が育ち、テスト手順や好みが次のエージェントに引き継がれる
- Slack監視、スケジュール実行、全PRフォローなどの**Subscriptions**で、指示なしでも動ける

## 2026年9月2日 — セルフホストマシン

ツール実行を自社ネットワーク内に閉じられる。

- **My Machines**：個人用の1台
- **Team pools**：需要に応じて増減するワーカーキュー。アイドル時はハイバネート可能
- 既存インフラ（AWS Lambda、Vercel、E2B など）でも実行可能
- Linux / Mac で **computer use**（クリック、入力、スクショ、ブラウザ操作）

## 2026年8月27日 — リポジトリなしで開始

GitHub などの SCM 接続なしで Cloud Agents を開始可能。

- 「Start from scratch」→ あとから **Origin** に保存
- クラウド環境のライブプレビュー
- Vercel 連携で公開（Vercel アカウント必須）

## 2026年8月19日 — Cloud Agents / ハーネス強化

常時稼働エージェント向けの改善。

- **Subscriptions**：PR・Slack・定期タスクで起動（現状は Cloud Agents のみ）
- **Custom modes**：スキルをチャットにピン留めして常時適用
- サブエージェントが**各自の VM**で隔離実行
- **`/goal`**：完了まで追い続ける長期目標
- 作業中の追指示が、途中切断せず次のツール呼び出しまで待つ

## 2026年8月17日 — Origin（コードホスティング、早期ベータ）

Cursor がリポジトリをホストできるようになった（有料プラン向け）。

- Origin ホスト repo は Origin が正
- GitHub 同期 repo は GitHub が正、Origin はミラー（PRコメントは双方向）
- コード閲覧・PR・エージェントが同じ場所に集約
- Vercel / Depot / Buildkite 連携あり

全体の流れは、「チャット1回」から「クラウド上で継続するエージェント基盤（Projects / Origin / セルフホスト）」へ、という方向です。
